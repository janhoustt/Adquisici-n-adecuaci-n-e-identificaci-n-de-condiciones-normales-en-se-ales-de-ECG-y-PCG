# Adquisici-n-adecuaci-n-e-identificaci-n-de-condiciones-normales-en-se-ales-de-ECG-y-PCG
Este proyecto presenta el diseño e implementación de un sistema para la adquisición simultanea, adecuación, análisis y comparación de señales electrocardiográficas y fonocardiográficas bajo condiciones normales. 
En este repositorio se encuentan:
- Informe con descripción de implementación y codigos realizados
- Codigo de MATLAB de la adquisición de ambas señales
- Codigo para el procesamiento para la señal ECG
- Codigo para el procesamiento para la señal PCG
- Codigo para la comparación de ambas señales
- Archivo .mat con datos de la señal ECG adquirida
- Archivo .mat con datos de la señal PCG adquirida
